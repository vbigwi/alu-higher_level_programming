# alu-higher_level_programming

Projects for the ALU "Introduction to Python Programming and Databases"
curriculum. Each directory holds one project with its own README.

## Projects

- `python-hello_world` - running Python, `print`, f-strings, string slicing
- `python-if_else_loops_functions` - conditionals, loops, `range`, functions
- `python-import_modules` - imports, modules, `__main__` guard, `sys.argv`
- `python-data_structures` - lists, tuples, slicing, comprehensions
- `python-more_data_structures` - sets, dictionaries, lambda/map/filter/reduce
- `python-exceptions` - try/except/finally, raising exceptions
- `python-classes` - classes, instances, private attributes, properties
- `python-more_classes` - __str__/__repr__/__del__, class attributes, static and class methods
