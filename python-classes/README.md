# Python - Classes and Objects

Seventh Python project of the ALU higher-level programming curriculum.
It introduces object-oriented programming: classes, instances, public and
private attributes, `__init__`, properties with getters and setters, and
documentation of modules, classes and methods.

## Files

| File | Description |
| ---- | ----------- |
| `0-square.py` | Empty `Square` class |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | `Square` with size type and value validation |
| `3-square.py` | `Square` with an `area()` method |
| `4-square.py` | `Square` with a `size` property getter and setter |
| `5-square.py` | `Square` with a `my_print()` method |
| `6-square.py` | `Square` with a `position` property used when printing |
