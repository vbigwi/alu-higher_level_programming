# Python - Data Structures: Lists, Tuples

Fourth Python project of the ALU higher-level programming curriculum.
It covers lists (indexing, slicing, copying, `del`), list comprehensions,
tuples, tuple packing and sequence unpacking.

## Files

| File | Description |
| ---- | ----------- |
| `0-print_list_integer.py` | Prints all integers of a list, one per line |
| `1-element_at.py` | Returns the element at an index, or `None` if out of range |
| `2-replace_in_list.py` | Replaces an element in place at a given index |
| `3-print_reversed_list_integer.py` | Prints all integers of a list in reverse order |
| `4-new_in_list.py` | Returns a copy of a list with one element replaced |
| `5-no_c.py` | Removes every `c` and `C` from a string |
| `6-print_matrix_integer.py` | Prints a matrix of integers |
| `7-add_tuple.py` | Adds two tuples element-wise, padding with 0 |
| `8-multiple_returns.py` | Returns the length and first character of a string |
| `9-max_integer.py` | Finds the largest integer in a list without `max()` |
| `10-divisible_by_2.py` | Returns a list of booleans for multiples of 2 |
| `11-delete_at.py` | Deletes the item at an index without `pop()` |
| `12-switch.py` | Swaps the values of `a` and `b` |
