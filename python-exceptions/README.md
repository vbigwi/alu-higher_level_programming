# Python - Exceptions

Sixth Python project of the ALU higher-level programming curriculum.
It covers the difference between errors and exceptions, `try`/`except`/
`finally`, raising built-in exceptions, and clean-up actions.

## Files

| File | Description |
| ---- | ----------- |
| `0-safe_print_list.py` | Prints `x` elements of a list safely, returns the number printed |
| `1-safe_print_integer.py` | Prints a value as an integer, returns whether it succeeded |
| `2-safe_print_list_integers.py` | Prints the first `x` integers of a list, skipping other types |
| `3-safe_print_division.py` | Divides two integers and prints the result in `finally` |
| `4-list_division.py` | Divides two lists element by element with error reporting |
| `5-raise_exception.py` | Raises a `TypeError` |
| `6-raise_exception_msg.py` | Raises a `NameError` with a message |
