# Python - if/else, loops, functions

Second Python project of the ALU higher-level programming curriculum.
It covers `if`/`elif`/`else`, `for` and `while` loops, `range`, string
formatting, `ord`/`chr`, and defining functions.

## Files

| File | Description |
| ---- | ----------- |
| `0-positive_or_negative.py` | Prints whether a random number is positive, zero or negative |
| `1-last_digit.py` | Prints the last digit of a random number and classifies it |
| `2-print_alphabet.py` | Prints the lowercase ASCII alphabet with one loop |
| `3-print_alphabt.py` | Prints the lowercase alphabet without `q` and `e` |
| `4-print_hexa.py` | Prints 0 to 98 in decimal and hexadecimal |
| `5-print_comb2.py` | Prints 00 to 99 separated by `, ` |
| `6-print_comb3.py` | Prints all combinations of two different digits |
| `7-islower.py` | `islower(c)`: True if `c` is a lowercase letter |
| `8-uppercase.py` | `uppercase(str)`: prints a string in uppercase |
| `9-print_last_digit.py` | `print_last_digit(number)`: prints and returns the last digit |
| `10-add.py` | `add(a, b)`: returns `a + b` |
| `11-pow.py` | `pow(a, b)`: returns `a` to the power of `b` |
| `12-fizzbuzz.py` | `fizzbuzz()`: prints 1 to 100 with Fizz/Buzz/FizzBuzz |
