# Python - import & modules

Third Python project of the ALU higher-level programming curriculum.
It covers importing functions and variables from other files, creating
modules, `dir()`, the `if __name__ == "__main__"` guard, and command
line arguments through `sys.argv`.

## Files

| File | Description |
| ---- | ----------- |
| `0-add.py` | Imports `add` from `add_0.py` and prints `1 + 2 = 3` |
| `1-calculation.py` | Imports `add`, `sub`, `mul`, `div` from `calculator_1.py` and prints results |
| `2-args.py` | Prints the number of command line arguments and lists them |
| `3-infinite_add.py` | Prints the sum of all command line arguments |
| `4-hidden_discovery.py` | Prints the public names defined by the compiled module `hidden_4.pyc` |
| `5-variable_load.py` | Imports the variable `a` from `variable_load_5.py` and prints it |
| `add_0.py`, `calculator_1.py`, `variable_load_5.py`, `hidden_4.pyc` | Helper modules provided by the project |
