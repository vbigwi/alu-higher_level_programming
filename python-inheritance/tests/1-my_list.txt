The ``1-my_list`` module
========================

Using ``MyList``
----------------

    >>> MyList = __import__('1-my_list').MyList

``MyList`` is a subclass of ``list``:

    >>> issubclass(MyList, list)
    True

An empty list prints as an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Elements are printed sorted in ascending order:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is not modified:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative integers are sorted too:

    >>> my_list = MyList([3, -1, 2, -5])
    >>> my_list.print_sorted()
    [-5, -1, 2, 3]

A list built from an existing list works:

    >>> my_list = MyList([9, 7, 8])
    >>> my_list.print_sorted()
    [7, 8, 9]

An already sorted list stays the same:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

Duplicates are kept:

    >>> my_list = MyList([2, 1, 2])
    >>> my_list.print_sorted()
    [1, 2, 2]

A single element:

    >>> my_list = MyList([42])
    >>> my_list.print_sorted()
    [42]

``print_sorted`` returns nothing:

    >>> my_list = MyList([2, 1])
    >>> my_list.print_sorted()
    [1, 2]
    >>> print(my_list.print_sorted())
    [1, 2]
    None

Calling with an argument fails:

    >>> my_list.print_sorted(1)
    Traceback (most recent call last):
    ...
    TypeError: print_sorted() takes 1 positional argument but 2 were given
