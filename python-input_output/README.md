# Python - Input/Output

Eleventh Python project of the ALU higher-level programming curriculum.
It covers reading and writing text files with the `with` statement, JSON
serialization and deserialization, and turning objects into dictionaries.

## Files

| File | Description |
| ---- | ----------- |
| `0-read_file.py` | Prints the content of a text file |
| `1-write_file.py` | Writes a string to a file and returns the number of characters |
| `2-append_write.py` | Appends a string to a file and returns the number of characters |
| `3-to_json_string.py` | Returns the JSON string of an object |
| `4-from_json_string.py` | Returns the object represented by a JSON string |
| `5-save_to_json_file.py` | Saves an object to a file as JSON |
| `6-load_from_json_file.py` | Loads an object from a JSON file |
| `7-add_item.py` | Adds command line arguments to a list stored in `add_item.json` |
| `8-class_to_json.py` | Returns the dictionary description of an instance |
| `9-student.py` | `Student` with `to_json()` |
| `10-student.py` | `Student` with filtered `to_json(attrs)` |
| `11-student.py` | `Student` with `reload_from_json(json)` |
| `12-pascal_triangle.py` | Returns Pascal's triangle of size n |
