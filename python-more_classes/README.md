# Python - More Classes and Objects

Eighth Python project of the ALU higher-level programming curriculum.
It builds a `Rectangle` class step by step: properties, `__str__` and
`__repr__`, `__del__`, class attributes, static methods and class methods.

## Files

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | Empty `Rectangle` class |
| `1-rectangle.py` | `width` and `height` properties with validation |
| `2-rectangle.py` | `area()` and `perimeter()` |
| `3-rectangle.py` | `__str__` drawing the rectangle with `#` |
| `4-rectangle.py` | `__repr__` usable with `eval()` |
| `5-rectangle.py` | `__del__` printing `Bye rectangle...` |
| `6-rectangle.py` | Class attribute `number_of_instances` |
| `7-rectangle.py` | Class attribute `print_symbol` |
| `8-rectangle.py` | Static method `bigger_or_equal()` |
| `9-rectangle.py` | Class method `square()` |
