# Python - More Data Structures: Set, Dictionary

Fifth Python project of the ALU higher-level programming curriculum.
It covers sets and their operations, dictionaries, and the `lambda`,
`map`, `filter` and `reduce` functions.

## Files

| File | Description |
| ---- | ----------- |
| `0-square_matrix_simple.py` | Returns a new matrix with every value squared |
| `1-search_replace.py` | Returns a new list with every `search` replaced by `replace` |
| `2-uniq_add.py` | Adds all unique integers of a list |
| `3-common_elements.py` | Returns the elements common to two sets |
| `4-only_diff_elements.py` | Returns the elements present in only one of two sets |
| `5-number_keys.py` | Returns the number of keys in a dictionary |
| `6-print_sorted_dictionary.py` | Prints a dictionary sorted by key |
| `7-update_dictionary.py` | Adds or replaces a key/value pair in a dictionary |
| `8-simple_delete.py` | Deletes a key from a dictionary if present |
| `9-multiply_by_2.py` | Returns a new dictionary with all values doubled |
| `10-best_score.py` | Returns the key with the biggest integer value |
| `11-multiply_list_map.py` | Multiplies every value of a list using `map` |
| `12-roman_to_int.py` | Converts a Roman numeral string to an integer |
