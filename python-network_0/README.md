# Python - Network #0

Twelfth project of the ALU higher-level programming curriculum.
It covers URLs, HTTP requests and responses, headers, status codes,
cookies and how to make requests with cURL.

## Files

| Script | What it does |
| ------ | ------------ |
| `0-body_size.sh` | Displays the size in bytes of the body returned by a URL |
| `1-body.sh` | Displays the body of a URL only when the status code is 200 |
| `2-delete.sh` | Sends a DELETE request to a URL and displays the body |
| `3-methods.sh` | Displays the HTTP methods a server accepts for a URL |
| `4-header.sh` | Sends a GET request with the header `X-HolbertonSchool-User-Id: 98` |
| `5-post_params.sh` | Sends a POST request with the `email` and `subject` parameters |

Every script is exactly three lines long and uses `curl -s`.
