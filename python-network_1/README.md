# Python - Network #1

Thirteenth project of the ALU higher-level programming curriculum.
It covers fetching internet resources with `urllib` and `requests`,
reading response headers and bodies, sending POST parameters, handling
HTTP errors and consuming JSON APIs.

## Files

| Script | What it does |
| ------ | ------------ |
| `0-hbtn_status.py` | Fetches the status page with urllib and prints the body |
| `1-hbtn_header.py` | Prints the `X-Request-Id` header of a URL with urllib |
| `2-post_email.py` | POSTs an email to a URL with urllib and prints the body |
| `3-error_code.py` | Prints a body or `Error code: <code>` with urllib |
| `4-hbtn_status.py` | Fetches the status page with requests and prints the body |
| `5-hbtn_header.py` | Prints the `X-Request-Id` header of a URL with requests |
| `6-post_email.py` | POSTs an email to a URL with requests and prints the body |
| `7-error_code.py` | Prints a body or `Error code: <code>` with requests |
| `8-json_api.py` | Searches a user by letter on the local API and prints `[id] name` |
| `10-my_github.py` | Prints a GitHub user id using Basic Authentication |
