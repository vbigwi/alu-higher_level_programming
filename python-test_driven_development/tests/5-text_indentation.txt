The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Each '.', '?' and ':' is followed by two new lines:

    >>> text_indentation("Hello. How are you? Fine: thanks")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

Text without any of those characters is printed as is:

    >>> text_indentation("Hello world")
    Hello world

Spaces around the separators are removed:

    >>> text_indentation("   Hello   .    World   ")
    Hello   .
    <BLANKLINE>
    World

Text ending with a separator:

    >>> text_indentation("The end.")
    The end.
    <BLANKLINE>

Several separators in a row:

    >>> text_indentation("Really?!.")
    Really?
    <BLANKLINE>
    !.
    <BLANKLINE>

An empty string prints nothing:

    >>> text_indentation("")

Only a separator:

    >>> text_indentation(":")
    :
    <BLANKLINE>

New lines already in the text are kept:

    >>> text_indentation("Line one\nLine two.")
    Line one
    Line two.
    <BLANKLINE>
